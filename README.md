# RealDoodle · descargas y actualizaciones

Aquí se publican las versiones de **RealDoodle**, un programa de dibujo
vectorial para Windows. Este repositorio solo contiene los instaladores; el
código fuente no se publica.

## Descargar e instalar

1. Abre la **[última versión](https://github.com/Alpes71/RealDoodle_updates/releases/latest)**.
2. En «Assets», descarga `RealDoodle-X.Y.Z-instalador.exe` (el archivo
   `latest.json` lo usa la app; no hace falta bajarlo).
3. Ejecuta el instalador. Al empezar te pregunta el idioma (español o
   inglés); luego puedes instalar solo para tu usuario o en la carpeta que
   elijas.

### Aviso de Windows

El instalador todavía no lleva firma digital, así que la primera vez Windows
SmartScreen puede mostrar «Windows protegió su PC». Pulsa **Más información**
y después **Ejecutar de todas formas**. Si el navegador avisa al descargarlo,
elige **Conservar**.

## Actualizaciones

No hace falta volver aquí: RealDoodle busca las versiones nuevas en este
repositorio (Ayuda › Buscar actualizaciones), descarga el instalador,
comprueba su tamaño y su huella SHA-256 y lo instala conservando tus ajustes.

# RealDoodle · downloads and updates

This is where **RealDoodle** releases are published (a vector drawing program
for Windows). This repository only holds the installers; source code is not
published.

1. Open the **[latest release](https://github.com/Alpes71/RealDoodle_updates/releases/latest)**.
2. Under “Assets”, download `RealDoodle-X.Y.Z-instalador.exe`.
3. Run it and choose English when it asks for the language.

The installer is not digitally signed yet: if Windows SmartScreen shows
“Windows protected your PC”, click **More info** and then **Run anyway**.
After that, RealDoodle finds, verifies and installs new versions by itself
(Help › Check for updates).
